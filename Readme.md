**ADDRESSBOOK**

**DESCRIPTION**

This project is about basically an online address book where one can add themselves to it or can actaully view the book from the page.

**By Mikwano Elizabeth**

**SETUP INSTRUCTIONS**

1. Ensure you have the download or clone of this project's repository.
2. Open the project folder in VS Code.
3. Ensure the HTML,CSS and JS files are in thier correct locations.
4. Right click on index.html and Open it with a live server whereby it will open in a browser(your default browser) to use the application.
5. You can click on view addressbook button inorder to see the people that have registered themselves an their details.
6. If one would like to add themsleves to it, they would have to click in the Add+ button and fill in the form displayed and submit it and refresh the page and can click on the view button inorder to see themselves.

**BUSINESS LOGIC**
This project uses a contact constructor to create people's information in a formatted way(fullname, email, address etc).And a prototype method that was used to return information about the place.
